# Desktop display patch

The exact supported original DLL is guarded by SHA-256 `7b819cb562826ae4d2592ff741877e76da0e57bfbe48192aabb79319fdb36823`. `GameplayPatcher` also checks the original method bodies of `ZombiesWP7.Game1.Draw` (token `060000cf`, SHA-256 `9a07780c3bcab593902543edd0b930e4920c380ba40f03d9f77bf6c609700680`), `IMAK3Z0MB1EGAEM.menu.Settings.Click` (token `060002c4`, SHA-256 `562c747623dfa56402f3b050d2d113fb7092e50fb23aa43c9e59978be5a7ebca`), and `Settings.Cancel` (token `060002c5`, SHA-256 `f9603f155bd0fa415014acf3d4f0fb7960ade1f793ccc1ea7060968645d162bd`).

The Draw patch calls `Port.Hooks.DesktopDisplay.BeginFrame` after the original text-bake path and `EndFrame` before `Game.Draw`. `BeginFrame` sizes the render target to the backbuffer aspect ratio and synchronizes `Game1.VIEWPORT`, `ScrollMan.screenSize`, and `VScroll.screenSize`; `EndFrame` fills the backbuffer using point sampling. The Settings.Click and Settings.Cancel patches first offer subpage actions to `DesktopDisplay`. The host reorganizes Settings into SFX, BGM, `DISPLAY`, and `T0UCH`. Touch reuses the original Vibration, Relative Controls, and Show Touchpads items and click handlers; Display and Custom Resolution swap in new native menu items. All pages use the original menu renderer. The postcondition checks confirm one call to each hook. Original Settings actions and the version-101 player save format stay unchanged.
