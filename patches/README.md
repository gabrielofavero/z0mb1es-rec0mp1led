# Guarded port patches

This folder holds authored patch specifications keyed to the original DLL hash and exact method signatures. Each entry states the expected original body, adaptation reason, bridge target, and test. The original DLL and decompiled source stay outside this folder. The first guarded adaptation is [menu media enumeration](menu-media-source.md).

The [expanded-inspired enhancements](expanded-enhancements.md) document the desktop presentation, settings, carousel, focus, and reduced-flashing hooks.
