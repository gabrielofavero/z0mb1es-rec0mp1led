# Expanded-inspired desktop enhancements

These adaptations apply only to the pinned phone DLL. `GameplayPatcher` verifies the original DLL SHA-256 (`7b819cb562826ae4d2592ff741877e76da0e57bfbe48192aabb79319fdb36823`), relevant method bodies, IL anchors, and the built `Port.Hooks` SHA-256 before writing a new prepared DLL. The emitted patch manifest records the added menu and light-row call targets.

- `DesktopDisplay.EndFrame` now samples the phone scene with `LinearClamp`, following the expanded project's output presentation. Resolution, aspect expansion, backbuffer mode, and pointer mapping remain coordinated through the existing display hook. This smooths fractional scaling; it does not add detail to the phone source textures.
- The Settings root presents Graphics, Audio, and Input. Audio and Input reuse the original SFX, BGM, vibration, relative controls, and touchpad items and their original click handlers. The first five original item slots remain present because `Settings.SetFromPlayer` and `Settings.Click` index them directly. Graphics retains display mode, preset, VSync, and custom resolution and adds a persisted Reduce Flashing toggle in `display.json`.
- `MainMenu.Draw` calls `MenuVisuals.DrawTitle` after the original scene draw. It uses the original text atlas, flashes while the carousel is visible, and stays steady when Reduce Flashing is enabled. `MenuItem.Draw` passes the foreground colors of normal and checkbox items through `MenuVisuals.Highlight`; only the controller or keyboard focused item gets the effect. The original focus, hit testing, and click handlers remain in place.
- `WorldTools.DrawLightRow` passes strobe color codes through `DesktopDisplay.SteadyLightRow`; Reduce Flashing maps them to steady white, blue, green, or red rows. Other light codes remain unchanged.
- `DesktopInput` keeps its existing eased carousel path but extends a page transition from 0.20 to 0.36 seconds. It also tolerates menu levels being added by the original loading thread while input is sampled.

Validation on 2026-11-07: Release and Debug hook builds passed with zero warnings; a guarded hook stage succeeded; `--check-load` prepared 818 methods across 177 game types; `Input.Checks` passed; the 17-level runtime menu probe passed, including Graphics, Audio, Input, VSync, presets, custom resolution, and the flashing toggle. The probe is automated and does not establish perceived smoothness or physical controller behavior.
