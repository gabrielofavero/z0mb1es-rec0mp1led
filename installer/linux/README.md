# Linux x64 packages (Prompt 2)

The locally built `.deb` and `.rpm` install only authored code, the .NET runtime, FNA and its native dependencies, the optional-art helper, and the WMA converter. No phone DLL, XAP, XNB, prepared art, or generated game content belongs in either package. Package scripts only place files under `/opt` and `/usr/share`; they do not ask for a XAP. The desktop entry starts `--linux`, which opens the first-launch GTK picker through Zenity. The package manager installs Zenity as a normal package dependency.

Before asset import or animated game content, the app displays a flashing lights warning. Choose **Continue** for standard effects or **Reduce Flashing & Continue** to enable Reduce Flashing. If Reduce Flashing is already enabled, **Standard Effects & Continue** switches to standard effects. The app saves the choice and acknowledgment beside the player's saves. **Quit** leaves the warning pending for the next launch. The warning shows once per save directory, including for existing installs that have yet to acknowledge it.

After the warning, choose the exact supported phone XAP. Supported I MAED Steam/360 and Time Viking 360 art sources are optional; the XAP alone supplies complete original art. The importer shows source version, selected-package size, estimated peak disk use, and available space before preparing into app data. A canceled or failed import can be retried next launch. Later use **Settings → Graphics → Assets → Reimport** to replace or add sources. Imported files are copied into `$XDG_DATA_HOME/z0mb1es-rec0mp1led` (default `~/.local/share/z0mb1es-rec0mp1led`); `assets`, `saves`, and `pictures` are separate folders. The original packages can be deleted after a successful import. Press **P** in the creator's picture mapper to select PNG/JPEG photos through the system dialog; selected files are copied to `pictures` for later sessions. Uninstalling a package leaves these user files unless the user removes them separately.

## Reproducible build inputs

- .NET SDK `10.0.302`; self-contained runtime packs `10.0.10` and their SHA-256 values are in `config/linux-packaging.json`.
- FNA managed `26.11`; the `2026-11-06` FNA native daily archive supplies SDL3, FNA3D, FAudio, and Theorafile. The archive and individual library hashes are pinned in `config/linux-packaging.json`.
- Rust `1.100.0` builds the WMA-to-QOA converter from `tools/audio-converter`; `package.sh` compiles it offline from vendored source and records its hash inside each package.
- Python `3.8.10`, the exact packages in `installer/linux/requirements-build.txt`, and the sibling `xnb_parse` checkout build the self-contained optional-art helper. Build it on an Ubuntu 20.04 x64 environment with `PYTHON=/path/to/venv/bin/python3 sh installer/linux/build-art.sh`.
- nFPM `2.48.0` builds both package formats from `installer/linux/nfpm.yaml`. Its archive SHA-256 is pinned in `config/linux-packaging.json`.

The `out/deps/cache` runtime packs, FNA native archive, frozen art helper, and nFPM binary are local build inputs under ignored directories. After those inputs are ready, run `python3 installer/linux/bootstrap-native.py` and `installer/linux/build.ps1` from PowerShell on the development machine; the latter cross-publishes Linux ELF binaries and invokes `installer/linux/package.sh` in WSL. Install Rust 1.100.0 in the Linux build environment. On a Linux developer machine, use the same `dotnet restore -r linux-x64 --source out/deps/cache` and `dotnet publish -c Release -r linux-x64 --self-contained true` commands for `Port.Launcher`, `inspect_assembly`, `abi_check`, and `decode_360_xnb`, placing outputs in `private/linux-publish/{game,inspect,abi,decode}`. Publish the ABI checker as a directory, not a single file, because it inspects the runtime assembly catalog. The inspector and decoder may be single files. Then run `sh installer/linux/package.sh`. Outputs are in `out/linux/packages`.

## Current acceptance

The 1.1.0 Rust-converter packages were built and tested on Ubuntu x64. The `.deb` installed in an isolated package root, and the `.rpm` passed its digest check and payload comparison. Both passed the content-free package audit.

The Zenity import flow accepted the supported phone XAP and both Xbox 360 artwork sources. It generated three QOA tracks and verified the I MAED, Time Viking, and Endless artwork. Reinstalling the `.deb` preserved the imported data, and the updated launcher reopened the game and wrote a save. The launcher passed all three gameplay probes, artwork toggling, and the 17-level menu probe on a virtual X11 display with Vulkan. SDL's disk audio driver captured gameplay audio. Fedora package-manager installation, physical controller input, and creator photo selection remain outside this verification.
