# macOS Apple Silicon build (Prompt 4 in progress)

The macOS host uses the shared first-launch import and Settings → Graphics → Assets → Reimport flow. It stores imported assets, saves, and creator photos in `~/Library/Application Support/z0mb1es-rec0mp1led/`, logs in `~/Library/Logs/z0mb1es-rec0mp1led/`, and keeps all generated content outside the app bundle. The first launch asks for the supported phone XAP; I MAED and Time Viking art are optional. Once import succeeds, the original packages may be removed. The app bundle and package must contain no XAP, phone DLL, XNB, or generated assets.

`build.sh` is configured for Apple Silicon only. Intel is not a promised build. The checked tool versions are .NET SDK 10.0.302, runtime 10.0.10, FNA 26.11, and Xcode 27.1. This Windows checkout cannot establish the Xcode or native library hashes. On a Mac, build or obtain matching arm64 SDL3, FNA3D, FAudio, and Theorafile libraries, plus the FFmpeg 8.1.1 converter and frozen optional-art importer. Record reviewed SHA-256 values for the exact local files in `config/macos-packaging.json` under `artifactHashes`. The script refuses to package while any pin is missing. The pinned source archives and commands are in `build-ffmpeg.sh`; `build-art.sh` uses the same Python requirements as the Linux importer. Runtime packs go in `out/deps/cache`, native libraries in `out/deps/native/osx-arm64`, and converter/importer binaries in `private/macos-inputs`.

Run `sh installer/macos/build.sh` on the Mac. It verifies hashes and architectures, publishes self-contained tools, audits bundle payloads for proprietary content, and builds an unsigned `.app` and `.pkg` in `out/macos/packages`. The ABI checker remains a directory publish so it can inspect the runtime assembly catalog. The package has no interactive install script; file selection occurs in the app on first launch. Run a clean Finder launch and import on real Mac hardware before calling the output usable. The guarded ABI report may require a reviewed macOS hash if its bytes differ from the pinned Linux report.

## Unsigned install

After downloading the package from a trusted project source, open the `.pkg`. If macOS blocks it, try opening it once, then go to **System Settings → Privacy & Security**, scroll down, click **Open Anyway**, and confirm **Open** in the next warning. Install the app, open **Z0MB1ES** from Applications, and repeat the same procedure for the app if macOS blocks its first launch. Apple documents this exact override for an unsigned app or installer in [Safely open apps on your Mac](https://support.apple.com/en-us/102445). No SDK or developer account is required for a player; the one-time security override is required.

The `build.sh` checks source binaries and audits staged bundle contents, but no `.app`, `.pkg`, graphical import, audio, controller, or gameplay test has been run on macOS yet. Do not distribute these provisional artifacts before the acceptance and device checks are recorded.
